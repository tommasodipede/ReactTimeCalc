# Hardware Components 

* **Microcontroller:** ESP32 Development Board (38-pin, Type-C USB, ESP32-32D/ESP32-DevKitC with CP2102)
* **IMU Sensor:** GY-BMI160 6-DOF accelerometer and gyroscope sensor module (SPI/I2C communication, 3-5V)
* **Audio Sensor:** KY-037 voice/sound detection microphone module
* **Display:** 0.96 inch OLED I2C 128x64 SSD1306 white display module
* **Prototyping Board:** MB-102 400-point solderless breadboard
* **Wiring:** 20cm Dupont jumper wires (Assorted Male-to-Male, Female-to-Female, and Male-to-Female)
